# Mamitha's Restarunt

A beautiful, functional front-end website for Mamitha's Restarunt built with HTML, CSS, and vanilla JavaScript. 

## Features
- Dynamic menu rendering with categories (Starters, Main Course, Drinks, Desserts)
- Fully functional shopping cart persistent via LocalStorage
- Real-time order summary calculations 
- Direct checkout/ordering via WhatsApp
- Responsive, warm, food-themed design
